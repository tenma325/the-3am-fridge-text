An entry for the make.fun bounty **"The 3AM Fridge Text"** (`u-deysumbrella-the-3am-fridge-text-4c3e721d`).

`main.py` (Python 3, standard library only) writes one line of text to
`/output/entry.txt`.

- No network access.
- Deterministic: every run writes exactly the same bytes.

## Run it

```bash
python3 main.py
# writes /output/entry.txt
```

For local testing you can redirect the output:

```bash
ENTRY_OUTPUT_PATH=./output/entry.txt python3 main.py
```
